# Employee Management System

This project is developed using Java and OOP concepts.

Features:

* Add Employee
* Display Employees
* Search Employee
* Update Employee Salary
* Remove Employee
* Filter Employees by Department
* Employee ID Validation

Concepts Used:

* OOP Concepts
* ArrayList
* Custom Exception Handling
* Java 8 Optional API
* Java 8 Streams
* Lambda Expressions
* Input Validation

Files:

* Employee.java
* EmployeeManagement.java
* EmployeeException.java
* Main.java

How to Run:

1. Open project in Eclipse
2. Run Main.java
3. Use menu options in console

Exception Handling:

* Invalid Employee ID
* Duplicate Employee ID
* Employee Not Found
* Invalid User Input

Java 8 Features:

* Optional API for safe employee retrieval
* Stream API for searching and filtering employees
* Lambda Expressions for displaying employee records
